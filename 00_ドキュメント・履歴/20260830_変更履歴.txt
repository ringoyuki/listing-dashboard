変更内容：APIキー保存ボタンが反応しないバグの修正
==================================================

【発生していた問題（なぜボタンが反応しなかったか）】
APIキーの入力欄から文字を読み取るための変数「apiKeyInput」がプログラム内で使われていましたが、
その変数を定義（準備）するコードが欠落していました。
そのため、保存ボタンを押した瞬間に「apiKeyInputという変数は存在しません」というエラーが裏で発生し、
保存処理が停止してしまっていました。

【行った修正内容】
変数「apiKeyInput」に入力欄（id="apiKey"）を指定する1行を、必要最低限の修正として追加しました。

▼ 修正前のコード（該当箇所）
`javascript
  // 保存ボタン
  document.getElementById('apiKeySave').addEventListener('click', () => {
    const key = apiKeyInput.value.trim();
    if (!key) { alert('APIキーを入力してください'); return; }
`

▼ 修正後のコード（該当箇所）
`javascript
  // 保存ボタン
  document.getElementById('apiKeySave').addEventListener('click', () => {
    const apiKeyInput = document.getElementById('apiKey'); // ← この1行だけを追加しました
    const key = apiKeyInput.value.trim();
    if (!key) { alert('APIキーを入力してください'); return; }
`

※ 上記の1行を追加したのみで、それ以外のシステムやデザイン、裏側の挙動には一切変更を加えていません。
※ 修正したファイルはGitHubへプッシュ済です。

【ご要望内容】
外注スタッフの方が作業しやすいように、古いAPIキーと新しいAPIキーなど、
2つのAPIキーを保存しておいて、クリック（ラジオボタン）で選べるようにしたい。

【行った変更の概要（必要最低限のコード修正）】
1. HTML側に「キー1」「キー2」を選ぶラジオボタンを追記しました。
2. JS側で、選択されているキー（キー1かキー2か）を判定して保存・読み込みを行うように修正しました。
3. 画像アップロード時にも、現在選択されている側のAPIキーを使って送信するよう連携させました。

※ この変更もすでにGitHubへ反映（プッシュ）済みです。
※ 「Ctrl+F5」で画面を更新すると、「imgbb APIキー設定」の枠内に「キー1」「キー2」のラジオボタンが現れ、それぞれ別々にAPIキーを登録して切り替えられるようになります。
